# Quality Mobile

**Module:** Quality  
**Version:** 1.0  
**Status:** Active design

---

# Purpose

Mobile surfaces for inspectors and operators performing quality jobs on the floor
or at receiving — not for engineering configuration of inspection plans.

---

# Authority references

Same as Quality Architecture. Scan displays IDs; minting → Numbering Service.

---

# Jobs

| Job | Screen map | Notes |
|-----|------------|-------|
| Run inspection from queue | QLT-004 / 005–007 | Pass/fail + samples |
| Raise NCR quickly | QLT-008/009 | Photo attach |
| Moisture / lab entry | QLT-017 | Timber |
| Approval decide | QLT-020 | Dual-control |
| Trace lookup | QLT-014 | Read-only |

---

# Capabilities

- Offline queue sync (conflict → supervisor)  
- Camera for evidence  
- Barcode/QR scan of lot/serial/package  
- Large-touch pass/fail  

---

# Not on mobile (v1)

- Inspection plan authoring  
- CAPA program administration  
- Certificate layout design

**Module:** Design System

**Category:** Brand

**Version:** 1.0

# Purpose

This document provides reference UI examples demonstrating how the Naswood Design System should be applied throughout the platform.

The examples illustrate layout, spacing, typography, colors, components and user interactions.

These examples are reference implementations rather than functional specifications.

✓ Use official layouts.

✓ Follow spacing system.

✓ Use semantic colors.

# Do

✓ Follow design system

✓ Reuse components

✓ Maintain hierarchy

✓ Respect spacing

✓ Keep consistency

# Don't

✗ Invent new layouts

✗ Mix component styles

✗ Ignore responsive rules

✗ Break typography hierarchy

✗ Overload dashboards

# Acceptance Criteria

Every example follows the official Design System.

Components are reused consistently.

Layouts remain responsive.

Brand identity is preserved.

Accessibility complies with WCAG 2.1 AA.

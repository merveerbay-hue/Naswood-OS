# Icons

**Module:** Design System

**Category:** Foundation

**Version:** 1.0

**Status:** Approved

---

# Purpose

This document defines the official icon catalog used throughout Naswood OS.

Every feature, module, action and workflow should use standardized icons to provide a predictable and consistent user experience.

Visual usage rules are defined in **Iconography.md**.

---

# Official Library

Primary Library

Lucide React

Secondary Library

Custom Naswood Icons

No other icon libraries are permitted.

---

# Color Rules

Icons inherit text color.

Semantic colors allowed only for

Success

Warning

Danger

Information

Do not manually color navigation icons.

---

# Accessibility

Decorative icons

aria-hidden="true"

Interactive icons

aria-label required

Icons never replace labels.

---

# Performance

Use SVG only.

Import individual icons.

Tree shaking enabled.

Avoid loading entire libraries.

---

# Best Practices

✓ Use Lucide React

✓ Import only required icons

✓ Maintain consistent size

✓ Pair icons with labels

✓ Keep visual consistency

---

# Do

✓ Use official icons

✓ Follow naming convention

✓ Keep icon sizes consistent

✓ Reuse existing icons

---

# Don't

✗ Mix icon libraries

✗ Create duplicate icons

✗ Stretch icons

✗ Rotate icons unnecessarily

✗ Use emoji as interface icons

---

# Acceptance Criteria

All modules use approved icons.

Icons match official naming.

No duplicate icon libraries exist.

Accessibility requirements are satisfied.

Performance impact remains minimal.

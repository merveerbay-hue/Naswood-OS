# Kanban

**Use for:** Dispatch boards, work-order boards, stage pipelines

## Anatomy

- Columns = status / work center / queue
- Cards = work items with priority, due, assignment
- Drag-drop transitions only when Workflow allows that edge
- Swimlanes optional (shift, line, technician)

## Rules

- Column set comes from Module Workflow, not arbitrary UI statuses
- Failed transition shows workflow reason, not silent revert

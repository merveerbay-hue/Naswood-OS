# Master Detail

**Use for:** Record workspaces with header + tabs/panes

## Anatomy

- Header: identity, status, key metrics, primary actions
- Tabs or panes: Lines, Workflow, Documents, History, Related
- Side context (optional): summary, AI hints, related links

## Rules

- Header actions are workflow verbs (Release, Confirm, Approve), not only Edit/Delete
- Dirty-state guard on navigate away
- Embed Audit Timeline and Approval Flow where process applies

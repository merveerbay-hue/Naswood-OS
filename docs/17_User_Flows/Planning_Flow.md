# Planning Flow

**Actors:** Production Planner, Capacity Planner  
**Workspace:** Production → Planning

---

## Path

1. Review demand / open orders (`PRD-010`)
2. Open order detail — dates, qty, priority (`PRD-011`)
3. Check capacity (`PRD-022`)
4. Schedule (`PRD-021`)
5. Publish dispatch list (`PRD-023`)
6. Monitor dashboard queues (`PRD-001`)

Planning does not include shop-floor confirmation (see Production Flow Execution steps).

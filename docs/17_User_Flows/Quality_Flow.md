# Quality Flow

**Actors:** Inspector, Quality engineer, Approver  
**Module:** Quality

---

## Inspection path

Plan → Incoming / In-Process / Final inspection screen → record results → pass/fail → certificate or hold

## NCR → CAPA path

1. Raise Non-Conformance (from inspection or production scrap)
2. NCR Detail — disposition, containment
3. Root cause
4. CAPA actions → verify effectiveness
5. Close with Audit Timeline

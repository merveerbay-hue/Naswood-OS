# Prompt Standards

**Project:** Naswood OS

**Document:** Prompt Standards

**Code:** AI-005

**Version:** 1.0

---

# 1. Purpose

This document defines the prompt standards used by Factory Copilot and AI Agents.

It ensures consistent, reliable and explainable AI interactions across the platform.

---

# 2. Objectives

- Standardize prompts
- Improve response quality
- Reduce ambiguity
- Support reusable prompt templates
- Maintain consistency

---

# 3. Prompt Structure

Every prompt should define:

- Role
- Context
- Objective
- Constraints
- Expected Output

---

# 4. Prompt Principles

- Be specific
- Use enterprise terminology
- Provide sufficient context
- Define expected output
- Avoid ambiguity
- Prefer structured responses

---

# 5. Prompt Types

- Information
- Analysis
- Recommendation
- Prediction
- Reporting
- Workflow
- Automation
